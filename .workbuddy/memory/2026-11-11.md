## 依赖更新（代码更新后全模块重建）

- 版本已更新至 1.0.3b5（commit cd17e8d3）
- **桌面端架构变更**：Wails v3 + Go → Electron + pnpm（`desktop/src/go.mod` 已删除，改用 `package.json` + `pnpm-lock.yaml`）
- Python 后端：`uv sync` 因 5 个纯 sdist 云 SDK（esdk-obs-python/oss2/crcmod/aliyun-python-sdk-core/cos-python-sdk-v5）构建后清理临时目录触发环境删除保护而失败

- uv run 前置环境检查也会重建 sdist 触发同样拦截 → 启动改用 `.venv/Scripts/python.exe -m octop.cli.main run`

- dashboard：npm install 正常
- 启动 Octop 需先停旧进程（venv 的 onnxruntime DLL 被占用会导致 uv sync 失败）
